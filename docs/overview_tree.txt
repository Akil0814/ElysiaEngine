`-- docs/                            -> project-level documentation

Dependency direction:

MoonLine -> game_lib -> engine_lib -> SDL

Notes:
1. Application is part of the reusable engine and must not include gameplay types.
2. Projects extend the runtime through IGameModule and game Scene keys 1..999.
3. Engine built-in Scenes use the high key range above 0xFFFF0000.
