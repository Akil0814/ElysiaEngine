# Elysia Engine Developer Documentation

**English** | [简体中文](../zh-CN/README.md)

This is the entry point for the English documentation. Whether you are developing a game with the engine or modifying its implementation, choose a guide according to your reading goal.

## Develop Games with the Engine

The [User Guide](user-guide/README.md) covers building and running, game module integration, scenes and objects, and the public interfaces of each subsystem. If you are new to the engine, start with [Core Concepts](user-guide/core_concepts.md) to understand ownership, execution timing, and coordinate spaces.

## Look Up Interfaces and Configuration Formats

The [Interface and Format Reference](reference/README.md) collects the contracts for UI, audio, input and control, physics, and resource JSON. User guides organize steps and examples by task; reference pages provide the complete calling rules.

## Understand and Modify the Engine

[Architecture and Module Design](architecture/README.md) explains responsibilities, dependencies, runtime flows, and lifecycles in the current implementation. Before modifying a subsystem, establish its boundaries with scenes, resources, and the game layer, then read the corresponding source.

The [Development and Contribution Guide](contributing/README.md) describes coding conventions, testing, and documentation maintenance for developers preparing code or documentation changes.

## Explore Designs and Plans

[Designs and Roadmap](design/README.md) records future capabilities and historical design discussions. A proposal does not mean an interface is implemented. For existing functionality, use the user guides, current architecture, and source code.

## Read Game Integration Receipts

[Integration receipts](integration/README.md) record engine interfaces delivered for game requests, migration steps, and actual validation results.
