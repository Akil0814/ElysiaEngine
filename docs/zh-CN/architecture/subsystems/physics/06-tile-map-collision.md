# 地图单元格碰撞

`set_tile_world` 根据借用的地图描述建立持久静态形状。每个占用单元格保留自己的坐标、过滤、材质和可选单向规则。地图必须在绑定期间保持存活。

## 修改地图后如何刷新

修改单元格后，调用 `update_tiles(begin, end)`，参数是包含两端的脏矩形。物理世界只重建该区域，不在每个固定步扫描整张地图。替换或清空地图会使旧接触失效，并安全回收原生标识。

越界策略为 `Block` 时建立四面边界墙，为 `Empty` 时不建立。支持负地图原点和非正方形单元格。

## 邻接与单向支撑

过滤相同的相邻实心单元格会抑制共享内部接触面，暴露面仍阻挡。脏区域更新在下一步刷新邻接信息；单元格身份和材质仍彼此独立。

单向决策读取冻结的当前与先前形状边界、接触法线和已接受的支撑接触。先前边界保留接近方向，即使离散接触在越过表面后才出现，也能判断来向。已有支撑在穿透修正期间继续有效，微小的求解器速度反转不会立即关闭它。

## 主动向下穿过平台

`request_pass_through` 只接受单向支撑，唤醒角色，并抑制指定对象对的接触，直到形状分离超过静止接触余量。角色跨越多个单元格时，需要为每个支撑对象对请求穿过；演示中的 Gameplay 辅助方法已统一处理。

当前适配器只公开矩形单元格，不包括斜坡、半格、分块流式加载或合并轮廓。
